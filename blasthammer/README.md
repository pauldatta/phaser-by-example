# Blast Hammer

A simple arcade game where you fly a spaceship and blast through walls.

## Controls

- **Arrow Keys**: Move the ship (Up for thrust, Left/Right to turn)
- **Right Mouse Button**: Fire the Hammer to destroy walls.

## How to Play

1.  Navigate to the `blasthammer` directory.
2.  Install dependencies: `pnpm install`
3.  Run the game: `pnpm dev`
